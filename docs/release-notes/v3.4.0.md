**3.4 adds 76 icons, for 140 in all.** Nothing is removed or renamed, and existing icons don't change, so upgrading needs no code changes. All the new icons come from Lucide and match the rest of the set ([0058](https://github.com/common-origin/common-origin-design-system/blob/main/docs/foundation/decisions/0058-lucide-icon-source.md)). [#386](https://github.com/common-origin/common-origin-design-system/pull/386)

**New icons:**
- **Drag:** `drag`, a grip of dots for drag-to-reorder handles.
- **Common UI:**
  - Account and settings: `settings`, `user`, `users`, `logIn`, `logOut`, `lock`, `unlock`
  - Actions: `download`, `share`, `send`, `attach`, `minus`, `undo`, `redo`, `save`, `sort`, `bookmark`, `tag`
  - Time: `calendar`, `clock`, `timer`, `history`
  - Places and media: `phone`, `location`, `globe`, `image`, `camera`
  - Views and files: `list`, `grid`, `folder`, `file`
  - Feedback and theme: `heart`, `help`, `sun`, `moon`, `thumbsUp`, `thumbsDown`
- **Meals and cooking:** `utensils`, `chefHat`, `cookingPot`, `shoppingCart`, `basket`, `fridge`, `microwave`, `weight`
- **Dishes:** `soup`, `salad`, `pizza`, `sandwich`, `burger`, `croissant`, `dessert`, `cake`, `coffee`, `wine`
- **Ingredients:** `beef`, `chicken`, `pork`, `fish`, `shrimp`, `egg`, `milk`, `wheat`, `nut`, `bean`, `carrot`, `apple`, `citrus`
- **Diet and allergens:** `leaf` (vegetarian), `vegan`, `glutenFree`, `nutFree`, `dairyFree`, `eggFree`, `spicy`

There are no per-country cuisine icons, because Lucide has none. For cuisines, use the dish icons, such as `pizza`, `soup`, `croissant` or `burger`.

**Bundle size:** `Icon` now loads only the icons' drawings, and leaves out their descriptions, aliases and labels. So a bundle that uses only Button stays small at 22.5 KB gzipped with all 140 icons (20.8 KB with 3.3's 64). `iconSet` still has everything and doesn't change.

**For contributors:** the icon set's single data file is now two: `src/styles/iconDrawings.json` (how each icon is drawn) and `src/styles/iconMeta.json` (its description, aliases and labels). `npm run icon:add` writes both, and a test checks they list the same icons. To change one of the system's own drawings (the status icons, carets or AI sparkle), edit `iconDrawings.json`.
