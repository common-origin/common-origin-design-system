**3.3 moves the icons to Lucide.** Nothing is removed or renamed, and icon names and props don't change, so upgrading needs no code changes, but every icon looks different ([0058](https://github.com/common-origin/common-origin-design-system/blob/main/docs/foundation/decisions/0058-lucide-icon-source.md)).

**Visual changes:**
- **The 50 general icons now come from [Lucide](https://lucide.dev):** line icons with 2px lines and round caps and joins. The line scales with the icon: 2px at `lg` (24px), 1px at `xs` (12px). Names and metadata don't change. Most icons look much as before; the clearest differences:
  - `menu`'s three lines are equal width.
  - `lineOut` is Lucide's external-link arrow, an arrow leaving a box.
  - `stop` is an outlined square, and `play` and `pause` have rounded corners.

  [#382](https://github.com/common-origin/common-origin-design-system/pull/382)
- **The status icons and carets are redrawn to match** ([#383](https://github.com/common-origin/common-origin-design-system/pull/383)):
  - Each coloured status icon (error, serious, warning, success, info, in progress) draws its 0045 shape as a 2px line, so the icon and the small shape indicator are the same shape. The icons are about 1px larger than before.
  - Pending, scheduled, not started and cancelled use the same line style.
  - The carets stay solid triangles, now with rounded corners.
  - The small status shape indicators don't change.
- **The AI sparkle stays solid**, so it still reads at 12px in a small AILabel.

**Smaller bundles:** the icons' data is about a third of its old size. A bundle that uses only Button drops from 37.3 KB to 20.8 KB gzipped.

**Added:** `iconSet`, every icon `Icon` draws with its metadata, where it comes from (Lucide or the system's own drawings), how it's painted and its shapes. Its types are exported too: `IconSet`, `IconDefinition`, `IconDescription`, `IconElement`, `IconElementTag`, `IconPaint` and `IconSource`. [#380](https://github.com/common-origin/common-origin-design-system/pull/380)

**Deprecated, removed in 4.0:** `iconsData`, `IconRegistry` and `IconMetadata`. `iconsData` is frozen at the 64 icons of 3.2.0, as the old single filled paths, so it doesn't show the new drawings and has no entry for icons added later. Read `iconSet` instead. [#380](https://github.com/common-origin/common-origin-design-system/pull/380)

**For contributors:** `npm run icon:add -- <lucide-name> --as <ourName>` copies an icon from Lucide into the set, so adding one no longer needs a trip through Figma. Lucide is a pinned dev dependency, not a runtime one. [#381](https://github.com/common-origin/common-origin-design-system/pull/381)
