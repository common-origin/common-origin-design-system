**The last 2.x minor before 3.0.** It gives every deprecated name a replacement you can move to now, so the 3.0 upgrade is only removals. The 3.0 scope is in [#99](https://github.com/common-origin/common-origin-design-system/issues/99).

**Changes to note:**
- **Text and icons on dark or coloured fills are `#fcfcfc`, not `#ffffff`** (decision 0049). `text.inverse` and `icon.inverse` now use `gray.100`, so Button, IconButton and Chip text on solid fills, and the hover and pressed mixes built from it, shift imperceptibly. Every pairing still meets AA: 15.51:1 on the primary Button. [#307](https://github.com/common-origin/common-origin-design-system/pull/307)

**New:**
- **Box `bg` accepts semantic token paths:** `surface.base`, `surface.raised`, `surface.scrim` and every `color.fill.*` fill, such as `bg="color.fill.muted"`. New types: `BoxBackground` and `DeprecatedBoxBackground`. [#305](https://github.com/common-origin/common-origin-design-system/pull/305)
- **`base.color.white`:** pure white, kept outside the colour ramps, for raised surfaces. `surface.raised` uses it, with no visual change. [#307](https://github.com/common-origin/common-origin-design-system/pull/307)

**Move off Box's old `bg` keys now:** `default` and `page` → `surface.base`; `subtle` → `surface.raised`; `overlay` → `surface.scrim`; `surface` → `color.fill.muted`. The rest become `color.fill.*`, with `interactive` → `accent`, `error` → `danger`, `neutral` → `default`, `-subtle` → `-muted` and `-active` → `-pressed`.

**Deprecated, removed in 3.0:** Box's old `bg` keys; `base.color.neutral.*` (`neutral.000` → `base.color.white`); and the old hue ramps `blue`, `green`, `red`, `orange`, `purple`, `pink` and `yellow`, replaced by the role and display ramps. [#308](https://github.com/common-origin/common-origin-design-system/pull/308)
