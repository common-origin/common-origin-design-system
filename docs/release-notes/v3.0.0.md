**3.0 removes what 2.x deprecated.** Upgrade to 2.23 first: it has every replacement, and TypeScript strikes through what's going. Then follow the **[migration guide](https://github.com/common-origin/common-origin-design-system/blob/main/MIGRATION-V3.md)**, which covers every change and the old-to-new name of each removed token.

**Breaking changes:**
- **Components removed:** `PageTitle` (use `Typography variant="h1"`), `StatusBadge` (use `StatusLabel`) and `CategoryBadge` (use `CategoryLabel`, with sizes one step up). [#311](https://github.com/common-origin/common-origin-design-system/pull/311)
- **Chips:** `BooleanChip` is now **`FilterChip`**, and the removable chip once called `FilterChip` is `InputChip`. Rename `FilterChip` → `InputChip` first, then `BooleanChip` → `FilterChip`; plain JavaScript gets no error if you do it the other way round. The static `Chip` has one look and no `onClick`; chips have no `size`; `ChipGroup` has no `variant`. [#312](https://github.com/common-origin/common-origin-design-system/pull/312)
- **Props and variants removed:**
  - Button and Modal `emphasis`
  - Badge `primary`, `error`, `warning` and `success`
  - Tag `success`, `warning`, `error` and `interactive`
  - CategoryLabel's old hue names
  - DateFormatter and DateGroup `relative`
  - Alert `inline` (use `InlineAlert`)
  - TabBar `variant`
  - Box's old `bg` keys (use token paths such as `surface.raised`)

  [#313](https://github.com/common-origin/common-origin-design-system/pull/313)
- **AgentInput's `enableVoice` defaults to `false`.** Grid `gap*` props take `base.dimension` keys or `auto`. [#313](https://github.com/common-origin/common-origin-design-system/pull/313)
- **433 deprecated tokens are removed**, with their CSS variables, including the `neutral` and Spectrum 1 ramps and the pre-0031 semantic names. No remaining token changes value. Box's spacing and radius names (`p="md"`, `borderRadius="circle"`) keep working. [#314](https://github.com/common-origin/common-origin-design-system/pull/314)

In plain JavaScript, a removed prop value falls back to the default look instead of crashing.
