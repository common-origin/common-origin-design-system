**3.2 adds a dark theme and rounds controls to 8px.** Nothing is removed or renamed, so upgrading needs no code changes, but some components look different.

**Dark theme:**
- **How to turn it on:** load `tokens.css` and set `data-co-theme="dark"` on any element; everything inside it takes the dark colours ([0054](https://github.com/common-origin/common-origin-design-system/blob/main/docs/foundation/decisions/0054-dark-mode-theme-mode.md)). Regions nest, `data-co-theme="light"` resets one, and density and theme can share an element.
- **It never turns dark on its own.** A product that wants to follow the system setting sets the attribute itself; the [dark mode guide](https://common-origin-design-system.vercel.app/guides/dark-mode) shows how to do it before the page paints.
- **Without `tokens.css`, components stay light**, because their fallbacks are the light values. Colours in your own CSS switch only if they come from the `--co-*` variables.
- **Contrast:** every token pairing meets WCAG AA in both themes. [#365](https://github.com/common-origin/common-origin-design-system/pull/365), [#366](https://github.com/common-origin/common-origin-design-system/pull/366), [#369](https://github.com/common-origin/common-origin-design-system/pull/369)

**Visual changes:**
- **Controls, rows and tabs have 8px corners**, the `md` step of the radius scale ([0055](https://github.com/common-origin/common-origin-design-system/blob/main/docs/foundation/decisions/0055-control-radius.md)):
  - **8px:** Button, IconButton, the input family, ListItem, SidebarNav rows and the selected tab.
  - **Unchanged at 4px:** Tag, Tooltip, CodeBlock, the Checkbox box, and buttons inside a field.
  - **Containers:** Alert and Modal round further so their corners nest around the controls inside them.

- **SidebarNav:**
  - The collapse toggle replaces the header in the rail, and expanding and collapsing no longer jumps.
  - The width eases out over `duration.moderate`, and the nav no longer has a right border.
  - Badge placement and the focus ring after a click are fixed, and empty rail sections fold away.
