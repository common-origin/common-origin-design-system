**Changes to note.** Nothing is removed or renamed, but these behave differently:

- **AgentInput's default status copy is gone.** With no `helperText` or `statusMessage`, the status line is empty (it used to read "Ask about transactions, spending, or transfers"). Set `helperText` to keep a hint. [#266](https://github.com/common-origin/common-origin-design-system/issues/266)
- **AgentInput's `errorMessage` shows whenever it's set**, in any state. It used to show only after an internal error. Clear it when the user retries. [#266](https://github.com/common-origin/common-origin-design-system/issues/266)
- **Unsupported voice is silent.** Where the Web Speech API is missing, the mic is hidden and no "not supported" message replaces the status line. `enableVoice` defaults to `false` in 3.0 ([#99](https://github.com/common-origin/common-origin-design-system/issues/99)). [#266](https://github.com/common-origin/common-origin-design-system/issues/266)
- **AgentInput's field stays editable while submitting.** Only Send is disabled (or becomes Stop with `onStop`). A follow-up typed meanwhile is kept when `onSubmit` resolves. [#267](https://github.com/common-origin/common-origin-design-system/issues/267)
- **AgentInput's field is a `textarea`.** It grows from one line to six; Shift+Enter adds a line and Enter sends. Use the ref handle or `getByRole('textbox')` instead of querying the inner `input`. [#268](https://github.com/common-origin/common-origin-design-system/issues/268)

**New:** AgentInput's ref handle, `onStop`, `maxLength`, `docked`, `review` and `suggestions` (decisions 0046 and 0047); `SuggestionChip`; `AILabel`; the `stop` and `ai` icons; the `color.text.ai` and `color.icon.ai` tokens; the base role and display hue ramps in OKLCH (decisions 0043 and 0044, no visible change).
